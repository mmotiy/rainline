# 第一轮浏览器渲染优化验证

日期：2026-10-15。Chrome headless、Windows、ANGLE D3D11、RTX 3080。
1920×1080、devicePixelRatio=1、内部 pixelRatio=1、Ultra。
未减少雨量、AO、SMAA、阴影分辨率、泛光或视距。

## 对照方式

同一版本分别关闭和开启城市分组剔除、AO 阴影复用。
关闭状态恢复原来的 BatchedMesh 无剔除绘制及 AO 重复更新阴影。
空间索引和性能计时器在两组中都存在，因此以下是渲染优化的对照，
不是完整旧版本与新版本的端到端基准。

固定视角冻结模拟和时间，使用 GPU timer query，逐帧同步采样。
这类采样用于比较渲染开销，不代表实际驾驶 FPS。

## 固定视角结果

| 视角 | 关闭优化 GPU ms | 开启优化 GPU ms | 像素最大差值 |
| --- | ---: | ---: | ---: |
| 初始车库夜景 | 11.96 | 9.46 | 0 |
| 市区夜景 | 27.17 | 11.13 | 0 |
| 市区夜景反向 | 30.57 | 12.28 | 0 |
| 港区白天 | 10.43 | 9.26 | 0 |
| 港区白天反向 | 8.87 | 7.35 | 0 |
| 山区黄昏 | 11.20 | 7.01 | 0 |
| 山区黄昏反向 | 11.58 | 10.83 | 0 |

初始视角全通道累计三角形约 610 万降至 386 万，绘制调用 875 降至 687。
以上七个视角均逐像素一致。该结论仅覆盖采样视角，并非所有可能状态的证明。

## 连续驾驶

分别在固定随机种子的独立页面启动，模拟油门输入，通过 requestAnimationFrame
驱动 240 帧，前 60 帧不计入帧间隔统计。逻辑步长固定为 16.7 ms。
采样阶段不使用 finish()，浏览器调度和 GPU 排队影响帧间隔。
GPU 计时排除初始化及着色器预热，数值为已平滑计时的中位数。

| 指标 | 关闭优化 | 开启优化 |
| --- | ---: | ---: |
| 平均帧率 | 34.4 FPS | 66.9 FPS |
| 帧间隔中位数 | 30.0 ms | 10.1 ms |
| P99 帧间隔 | 60.0 ms | 30.1 ms |
| CPU 整帧提交耗时中位数 | 9.3 ms | 11.6 ms |
| GPU 已平滑耗时中位数 | 26.9 ms | 12.1 ms |

剔除增加了一部分 CPU 工作，换取更少的 GPU 工作；CPU 受限机器需要另测。
短时测试的平均帧率不代表最低帧率，也不代表锁定 60 FPS。

## 正确性与范围

- 7 个 Node 单元测试通过。
- 游戏加载及测试过程中无脚本异常。
- 20 组画质/相机位置组合涵盖高空、负坐标、远距离传送及返回。
  所有格子的 LOD/卸载状态均与原全量距离判断一致。
- 城市候选格子检查 22,541 次，原全扫描为 152,440 次，减少约 85.2%。
  这是检查数量的减少，不是声称 CPU 耗时减少相同比例。
- 驾驶冒烟测试移动约 96 米，最高约 155 km/h，内部 pixelRatio 保持 1。
- 原有自适应分辨率逻辑保留；这些对照测试没有利用它降低测试分辨率。
- Web Workers 和 WebGPU 尚未迁移。本轮保留 WebGL2 和现有材质、后处理。
- 尚未用 GTX 1660、RTX 2060、RTX 3060 等中端显卡实测，不能保证其最高档 60 FPS。
